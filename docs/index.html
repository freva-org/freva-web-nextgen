@freva-org/data-inspector

Climate file inspection dialog with aggregation configuration and embedded 3D viewer support.

npm i @freva-org/data-inspector

Quick start

// 1. Install
npm install @freva-org/data-inspector

// 2. Import (registers the custom element)
import "@freva-org/data-inspector";


<!-- 3. Use anywhere -->
<data-inspector id="inspector" file="/data/my.nc"></data-inspector>

<script type="module">
  const el = document.getElementById("inspector");
  el.addEventListener("inspector-submit", ({ detail }) => {
    console.log(detail.file, detail.aggregationConfig);
  });
  el.setAttribute("open", "");
</script>
