browser-python console

Python runs in a Web Worker in this tab. No server, no kernel. Press Enter to run.

Try

  • State: value = 40 then value + 2
  • Multi-line: def double(v): … return v * 2 … blank line
  • Top-level await: import asyncio; await asyncio.sleep(0)
  • Completion: type json.dum and press Tab
  • History: press ↑, or Ctrl+R to search
  • Plot: import matplotlib.pyplot as plt; plt.plot([1,4,9]); plt.show()
  • Remote Zarr (needs the xarray + zarr profile): import xarray as xr; ds = xr.open_zarr(URL, consolidated=True, chunks=None)
