Freva client · in this browser

Nothing to install. freva_client is already imported-ready when the prompt appears. Do not run micropip.install("freva-client") - that fetches the unmodified PyPI wheel, which requires intake-esm, which pins polars<1.33 against the runtime's 1.33.1. That is the conflict this profile exists to avoid. 

from freva_client import authenticate, databrowser

token = await authenticate(host="https://eve.dkrz.de", timeout=180)

db = databrowser(host="https://eve.dkrz.de")
print(len(db))

authenticate is awaitable here on purpose - the device flow is network work, and blocking on it would freeze the page's only thread. A live host must permit this origin; browser Python cannot bypass CORS. db.intake_catalogue() will tell you why it is not available.
