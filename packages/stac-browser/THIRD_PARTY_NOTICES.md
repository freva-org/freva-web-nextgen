## Fonts

STAC Browser bundles **no** web font. It renders in the visitor's system UI
stack. Nothing is fetched from Google Fonts or any other remote font host.

## Map tiles and remote services

The compiled application ships **no** map imagery. Basemap tiles are fetched by
the visitor's browser at map-view time from the provider configured in
`basemaps.config.js`. At the pinned revision the defaults are:

| Body               | Provider                        | Endpoint                                         | Attribution rendered            |
| ------------------ | ------------------------------- | ------------------------------------------------ | ------------------------------- |
| Earth              | OpenStreetMap standard tiles    | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | `© OpenStreetMap contributors.` |
| Moon, Mars, Europa | USGS Astrogeology planetary WMS | `https://planetarymaps.usgs.gov/cgi-bin/mapserv` | `USGS Astrogeology`             |

Both are HTTPS, carry no API key, and render their attribution in the
OpenLayers attribution control. See
[`packages/portal/docs/licensing.md`](../portal/docs/licensing.md) for the tile
usage-policy assessment and how to substitute an institutional tile provider.
