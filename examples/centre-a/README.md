# Centre A (customisation fixture)

A fictional portal that exercises the customisation surface: a centred, sticky logo header that
is transparent over the hero, a columns footer with a logo wall, a three-column landing grid and
a `portal-style-v1` stylesheet (`brand/site.css`). See `docs/customisation.md`.

```console
freva-portal-builder build --source-root . --config portal.yaml --out ../../build/centre-a
```
